Mama's Buka Rush: run Ada's Lagos street-food buka — cook jollof, suya, puff puff, egusi and dodo against the clock, plate them and serve before patience runs out. Orders come in as tickets on the board; each dish cooks on its own station (charcoal grill, jollof pot, fryer, soup pot), waits a few seconds, then burns. A 150-second shift, three strikes, tips for fast service, and a rush that gets faster as the shift wears on. Keyboard and mouse, no network, no libraries — just static files and the WebAudio sizzle.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and press Enter to start the shift. Move with WASD / arrows / click, use with E, pause with P, mute with M.
